# Data-Driven Customer Churn Analysis and Prediction Using Data Analytics and AI

## 📌 Project Overview

This project focuses on analyzing customer churn using Data Analytics, Exploratory Data Analysis (EDA), Data Visualization, Feature Engineering, and Machine Learning techniques.

The main objective is to understand customer churn patterns, identify important factors associated with customer churn, and develop a Machine Learning model for churn prediction.

## 🎯 Objectives

- Perform data cleaning and preprocessing.
- Handle missing and inconsistent values.
- Identify duplicate records.
- Perform Exploratory Data Analysis (EDA).
- Create meaningful data visualizations.
- Analyze factors affecting customer churn.
- Perform correlation analysis.
- Apply feature engineering.
- Build Machine Learning models.
- Evaluate model performance.
- Generate useful business insights.

## 🤖 Machine Learning

Machine Learning techniques are applied to predict customer churn based on customer and service-related features.

The model is evaluated using appropriate performance metrics, confusion matrix, and feature importance analysis.

## 📈 Analysis Areas

The project analyzes factors such as:

- Customer demographics
- Tenure
- Monthly charges
- Total charges
- Contract type
- Internet service
- Payment method
- Service subscriptions
- Customer churn
